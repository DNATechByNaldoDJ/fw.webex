🚀 **Nova classe WebExDataTable: Revolucione suas tabelas dinâmicas no FWWebEx!**

Desenvolvedores Totvs Protheus, atenção! Acabei de lançar a classe WebExDataTable, uma extensão poderosa da WebExTable que integra perfeitamente o DataTables.js para criar tabelas interativas e eficientes. 

Projetada para lidar com grandes volumes de dados, ela suporta processamento server-side, garantindo performance otimizada mesmo em consultas pesadas.

Principais vantagens:

- Colunas customizadas: Adicione headers, fields e renderers JS personalizados com facilidade – ideal para formatações específicas como moedas, datas ou links.
- Ações por linha: Inclua botões de ação (ex: editar, visualizar, excluir) com ícones, classes e eventos onclick, tudo configurável via código.
- Integração AJAX flexível: Defina funções pré e pós-inicialização, além de uma função AJAX customizada para buscar dados do servidor de forma assíncrona.
- Opções avançadas: Controle total sobre as configurações do DataTable, como paginação, ordenação, busca e internacionalização (ex: suporte a pt-BR nativo).
- Server-side ready: Ative o modo server-side para processar filtros, ordenações e paginações no backend, evitando sobrecarga no cliente.

O melhor? Você no controle do código! Como o FWWebEx é open-source e liberado para domínio público, você tem acesso total ao fonte para modificar, estender ou integrar conforme suas necessidades. 

Nada de caixas-pretas – transparência e flexibilidade para acelerar seu desenvolvimento web no Protheus.

Experimente agora e transforme suas interfaces! Código disponível no GitHub: [link para o repo](https://github.com/DNATechByNaldoDJ/fw.webex/blob/main/src/fw.webex/contrib/fw.webex.datatable/fw.webex.datatable.tlpp).
