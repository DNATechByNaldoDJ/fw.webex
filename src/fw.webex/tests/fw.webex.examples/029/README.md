# Exemplo 029 - DataTable Form Integrado

Exemplo client-side integrando `WebExDataTable` com `WebExDataTableForm`.

- Usa dados em memoria no `DataTable`.
- Abre o modal de edicao com duplo clique na linha.
- Reaproveita a mesma configuracao de campos no grid e no formulario.
- Atualiza a linha editada sem backend, usando `SetUpdateFunction()`.

Execute `u_FWWebExExample_029()` ou abra pelo menu `u_FWWebExExample_000`.
