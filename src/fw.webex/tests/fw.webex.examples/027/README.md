# Exemplo de uso (27)

Exemplo minimo do bootstrap configuravel do runtime FWWebEx.

Ele cobre:
- `FWWebEx.config`
- `FWWebEx.init(config)`
- `FWWebEx.ready(fn)`
- hooks `beforeInit`, `afterInit` e `onError`
- binding declarativo via `FWWebEx.Actions`
