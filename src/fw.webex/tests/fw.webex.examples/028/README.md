# Exemplo 028 - DataTable Form

Exemplo minimo do `WebExDataTableForm`.

- Gera campos a partir da mesma configuracao usada pela `WebExDataTable`.
- Abre o formulario em modal Bootstrap nos modos `view` e `edit`.
- Demonstra campos obrigatorios, readonly, hidden, checkbox e lookup fixo.
- Mostra o payload do submit local no log da pagina.

Execute `u_FWWebExExample_028()` ou abra pelo menu `u_FWWebExExample_000`.
