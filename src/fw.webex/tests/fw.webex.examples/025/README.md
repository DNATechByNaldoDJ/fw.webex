## 📊 Presets de Animação (FWWebExAsciiEngine)

| Perfil                    | interval | frameTimeFactor | maxFrameTime | Sensação / Uso                          |
| ------------------------- | -------- | --------------- | ------------ | --------------------------------------- |
| 🟢 **SUAVE (Padrão)**     | 80       | 1.8             | 180          | Fluido, equilibrado, ideal pra produção |
| 🔵 **RÁPIDO**             | 60       | 1.5             | 140          | Ágil, moderno, bom pra dashboards       |
| 🟡 **LENTO (Cinemático)** | 100      | 2.2             | 220          | Mais “dramático”, bom pra demos         |

---

## 🧠 Regra Prática (faixa segura)

| Parâmetro         | Faixa Ideal | Observação            |
| ----------------- | ----------- | --------------------- |
| `interval`        | 60 ~ 100    | Base da velocidade    |
| `frameTimeFactor` | 1.5 ~ 2.2   | Ajuste fino do ritmo  |
| `maxFrameTime`    | 140 ~ 220   | Limite pra não travar |

---

## ⚠️ Leituras rápidas (pra não errar nunca)

* 🔥 **interval baixo + factor baixo** → tremedeira
* 🐢 **interval alto + factor alto** → parece travado
* 🎯 **equilíbrio** → fluidez
