# Exemplo 030 - ASCII Page Loader

Exemplo de uso real do `WebExAsciiLoader` como overlay de carga de pagina.

- Mostra uma animacao ASCII durante a inicializacao.
- Simula etapas de runtime, assets, dados e interface.
- Usa `FWWebEx.ready()` para iniciar o fluxo no momento correto.
- Libera o conteudo da pagina quando a carga termina.
- Inclui botao para reexecutar a experiencia.

Execute `u_FWWebExExample_030()` ou abra pelo menu `u_FWWebExExample_000`.
